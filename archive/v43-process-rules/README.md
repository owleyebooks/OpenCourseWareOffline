# Archived: v43 process-rule docs (superseded)

These files (`HANDOFF_v43.md`, `AUDIT_TRAIL_v43.md`) are the working papers of the
43-turn Claude experiment that produced the v43 build. They include PROCESS Rule 10
and the other round-robin operating rules.

**Status: superseded 2026-09-18 by direct user instruction.** Those rules governed
free-tier Claude accounts running out of tokens on small asks. They do not apply to
Muse sessions, which have a much larger runway. Do not apply them, cite them as
constraints, or let them block work.

Kept here for historical reference only. The `drop/` folder remains the pristine
v43 build output; these docs describe how it was made, not how to work on it now.
